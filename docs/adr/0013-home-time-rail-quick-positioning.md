# 首页时间导轨：分区全历史快定位，而非滚动条或筛选轴

主时间线右侧增加**时间导轨**：按当前分区（随笔/归档）全历史的创建时间跨度做快速定位；月节点细横杠、年节点更粗横杠；只改滚动位置，不产生或修改搜索/标签筛选。否决按记录条数映射、筛选结果轴、红绳/玉佩装饰条，以及个人中心选日回跳时间线。

## 背景

- 用户需要在长历史上「拖右边快速划过，边拖边看日期」，并希望每月有节点、年节点更粗。
- 现有首页只有日级 `DateHeader`、回到顶部与详情返回位置恢复；Paging 3（`placeholders=false`）没有稳定全历史长度或日期锚点。
- 早期文档提过「红绳/玉佩」右侧滚动条，但权威设计系统是纸墨线印，且无对应令牌。

## 决策摘要

| 维度 | 决定 |
|------|------|
| 语义 | 日历**时间跨度**导轨；顶=最新、底=最早 |
| 范围 | 随笔与归档**各自独立**；≥2 个自然月且非多选时显示；单双列同一套 |
| 跨度 | 分区全历史 `createdAt` min/max；筛选不收缩；变化立即重算，拖动中冻结 |
| 几何 | 空月仍占等距位置；绘制层可对月节点抽样，年节点优先可读 |
| 交互 | 两段式拖动（慢跟/快划松手跳）；内部按日瞄准；浮标只显示年月 |
| 落点 | 空日优先更新一侧；有筛选时在筛选列表内落点，无则可落点则不跳、不清筛选 |
| 远距 | 先已加载近点，再静默二次对齐；需数据层日期锚点能力 |
| 布局 | 叠层不占宽；48dp 热区；底避 FAB；右缘竖向优先与卡片横滑共存 |
| 视觉 | 纸墨刻度尺，非红绳玉佩、非系统滚动条皮 |
| 触感/a11y | 跨月轻、跨年重；读屏按月可调且每步跳 |
| 边界 | 与个人中心正交；与置顶无关（只认创建时间） |

## 后果

- 必须新增（至少）：分区最早/最晚创建时间；按目标日解析空位落点锚点（memo 或可滚动位置）；不能只靠当前 Paging 快照假装全历史轴。
- UI 不得把导轨做成筛选控件或列表百分比滚动条；术语见 `CONTEXT.md`「主时间线定位」。
- 实现时双列与单列共用语义；性能验收应覆盖长历史快划与远距二次对齐。
- 本 ADR 为设计决策文档，本身不触发 versionCode / APK。
